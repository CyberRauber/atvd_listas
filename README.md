# Atividades de listas

Este repositório é para guardar as listas de exercícios e as atividades da disciplina.

Cada lista fica em uma pasta separada. As respostas ficam no arquivo `README.md` de cada lista. Quando tiver uma parte prática, os códigos em HTML, CSS e JavaScript ficam dentro da pasta `parte_c`.

## Organização atual

```text
atvd_listas/
├── README.md
└── lista04/
    └── README.md
```

Por enquanto, a lista 04 é a que está neste repositório. As próximas listas podem ser adicionadas em pastas próprias, seguindo a mesma organização.

## Sobre os arquivos

- `README.md`: descrição do repositório e organização das listas.
- `listaXX/README.md`: respostas das questões da lista.
- `listaXX/exercicios.pdf`: arquivo com os exercícios passados em aula.
- `listaXX/parte_c/`: códigos da parte prática, quando houver.
